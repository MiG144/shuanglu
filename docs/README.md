# 双陆棋 · 文档索引

本目录存放双陆棋项目（中式打双陆）的规则与研究资料。规则依据为**宋代洪遵《谱双》**，以《欣赏编》十四卷（明·沈津编，明正德六年刊本）扫描本识别核对，并以识典古籍电子本（翁同龢清抄本）互校。

## 目录结构

```
docs/
├── README.md                  # 本索引
├── rules/                     # 规则文档（现行）
│   └── shuanglu-rules-v0.3.md # ★ 现行规则定稿（权威依据）
├── research/                  # 研究资料
│   └── pushuang-ocr-fulltext.txt  # 《谱双》五卷全文 OCR 文本（含置信度，供校对）
├── archive/                   # 历史版本（已被 v0.3 取代，仅存档）
│   ├── shuanglu-rules-draft-v0.1.md  # 需求期草案（含当时待定点）
│   └── shuanglu-rules-v0.2.md        # 依据识典古籍本初定稿
└── 欣赏编….pdf               # 《谱双》全书扫描原件（约 27MB，仅本地，不入库）
```

## 版本脉络

1. **v0.1（草案）**：需求期根据公开文献整理，标出待定点。
2. **v0.2（定稿）**：依据识典古籍电子本《谱双》卷五原文，落定大部分规则。
3. **v0.3（定稿·现行）**：通过识别《欣赏编》本扫描 PDF 全书五卷，逐条核对并大幅补充——确认双采/摆位/入局/拈出等细节，新增三骰变体、地域双陆规则、南北局例术语。**当前实现以此为准。**

> 重要更正：v0.1 曾误判"唐制双陆为进内盘即胜"（乙方案），v0.3 依据《谱双》原文"马先出尽为胜……胜双筹"确认为**拈出离盘（甲方案）**。详见 v0.3 §1.3b 与 §8。
