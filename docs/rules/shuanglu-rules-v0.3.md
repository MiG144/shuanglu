## 1. 常局格制（北双陆／总则，全书主干，原文逐句）

> 原文："雙陸率以六為限。其法左右各十二路，號曰梁。白黑各十五馬。右前六梁、左後一梁，各布五馬；右後六梁，二馬；左前二梁，三馬。白黑相偶。用骰子二，各以其采行。白馬自右歸左，黑馬自左歸右。或以二骰之數共行一馬，或行二馬，或移或疊。凡馬單立，則敵馬可擊。兩馬相比為一梁，它馬既不得打，亦不得同途。凡遭打，必候元入局處空位、與采相當，始得下。謂如第二梁空，今摸得二采，則下。所打者未下，則它馬不得行。至後六梁，謂之疊梁。凡疊梁已滿，如打得它馬，即併馬於近下五路。凡開後一梁為敵人地，若不獲它馬，即盡移歸頭梁之內。每擲視其彩拈出二馬。數有餘則取，不足則否。彩小不取，則併移歸下梁。常須固兩馬，不可移動，動則頭破。後六梁謂之末梁，馬先出盡為勝。而他馬未歸梁，或歸梁而無一馬出局，則勝雙籌。凡賞罰之籌，唯所約，無有定數。"

（录入以《欣赏编》本文字为准；个别字结合通行本校订。）

### 1.1 总则要点（v0.2 已实现，复核一致）

| 项 | 规则 | 原文依据 |
|---|---|---|
| 棋盘 | 24 梁（左右各十二路），两门，以六为限；四区各六梁 | "率以六為限……左右各十二路" |
| 马数 | 白黑各十五 | "白黑各十五馬" |
| 摆位 | **右前六梁 5 马、左后一梁 5 马、右后六梁 2 马、左前二梁 3 马；白黑相偶** | "右前六梁……三馬" |
| 骰子 | 两枚，各以其采行 | "用骰子二" |
| 方向 | 白马自右归左，黑马自左归右 | "白馬自右歸左，黑馬自左歸右" |
| 分走/合走 | 二骰可共行一马，或行二马，或移或叠 | "或以二骰之數共行一馬，或行二馬，或移或疊" |
| 打马 | 单立马可击 | "凡馬單立，則敵馬可擊" |
| 卡位 | 两马相比为一梁：不可打、不可落（同途）| "兩馬相比為一梁，它馬既不得打，亦不得同途" |
| 单梁上限 | 一道不得过六马 | 卷五·南北局例："兩馬相比為梁一道，不得過六馬" |
| 入局 | 界外按采数复进（"与采相当"）；未复进前他马不得行 | "必候元入局處空位與采相當始得下……所打者未下則它馬不得行" |
| 玄梁/末梁 | 后六梁，入内后方可拈出 | "至後六梁謂之疊梁……後六梁謂之末梁" |
| 拈出 | 每掷视彩拈出，有余则取不足则否；彩小不取则移归下梁 | "每擲視其彩拈出二馬，數有余則取，不足則否" |
| 固两马 | 常须固两马，动则头破（战术约束，非强制禁止） | "常須固兩馬，不可移動，動則頭破" |
| 终局 | 马先出尽为胜；敌未归梁或归梁无马出局则双筹 | "馬先出盡為勝……勝雙籌" |
| 计筹 | 唯所约（对局约定），无定数 | "凡賞罰之籌，唯所約，無有定數" |

### 1.2 先后手与掷骰顺序（v0.3 补充）
- 卷二百双陆原文："凡置局，二人白黑各以十五馬為數，用骰子二，**據彩數下馬**。白馬自右歸左，黑馬自左歸右。凡馬盡過門後，方許對彩拈出。……馬先盡贏一等，或盡而敵馬未拈，贏雙籌。"
- 即：对局时先用骰子掷彩，**按采数下马/行马**；与 v0.2 的 T4 默认（各掷一骰比大定先手）不冲突，更明确的是"先掷彩、按彩行"的流程。
- **引擎层无改动**：先手默认人类先行（可配置），掷彩后按采行走。

### 1.3 双采（v0.3 补充细节）
- 《卷三·下赞双陆》原文："凡遇雙采、雙幺、雙二、雙三之類，**併移四馬**，如彩數。謂如擲雙三，則四馬皆進三路。又**賞一擲**。番禺人多為之。"
- 佐证 v0.2 的 D1 默认（双采走四步），并新增细节：部分变体"赏一掷"（双采后额外再掷一次）。
- **引擎默认**：双采按四步走（`doublesFourMoves: true` 已是默认）；"赏一擲"作为**可选变体配置**（`doublesBonusRoll`），默认关。

## 2. 地域变体（卷二、卷三、卷四，v0.3 新增）

### 2.1 平双陆（卷二百双陆/平双陆）——就是常局格制的实际玩法
"凡置局二人白黑各以十五馬為數用骰子二據彩數下馬，白馬自右歸左黑馬自左歸右，凡馬盡過門後方許對彩拈出……馬先盡贏一等，或盡而敵馬未拈，贏雙籌。"
- 与卷五常局完全一致 → 引擎即按此实现。

### 2.2 打间双陆
- 原文："下馬行馬出馬與平双同。**段馬十有五而十二馬歸至一，兩兩相比，此間一路無馬故之間**。贏一等，再成又勝……或五路成雙，一路馬單即不得發。"
- 核心：15 马中 12 马两两成对比邻，间留一路空（"打间"），其余规则同平双陆。
- **引擎**：作为可选玩法配置（初始布局使用"12 马成对间空一路"式摆位）。

### 2.3 回回双陆（大食系）
- 原文："行馬大致與平雙陸相類，但**出局時不問點色多少，任意出兩馬**。"
- 差异点：**拈出不按采数，任意出两马**。
- **引擎**：变体配置 `bearOffArbitraryTwo: true`（调用点在拈出阶段）。

### 2.4 七梁双陆
- 原文："兩馬相比為梁，**十四馬行過一，就七路雙立**，故曰七梁。凡成七梁，贏一等，再成又勝……（同平雙）……如起馬先盡，而敵馬未成七梁，即勝雙籌；如未成七梁、馬未盡歸，擲出大采但移動後一梁馬之揭頭，輸三不下。"
- 核心：以**七路**为攻守重点，成七梁赢筹。
- **引擎**：变体配置（待细化，作为后续高级玩法）。

### 2.5 三梁双陆（最新发现：三骰）
- 原文："一名漢……家雙睦。**馬分為三，以三骰子對彩而行**，進兩馬或三馬，僻行一馬亦可。局終出如常法。"
- 关键：**三梁双陆使用三枚骰子**，马分三处。
- **引擎**：变体配置 `diceCount: 3` + 摆位三分（v0.3 起支持骰子数可配置）。

### 2.6 罗嬴双陆（广州系）
- 原文："用骰子二，隨彩下馬，白馬自右歸左黑馬自左歸右，行路出局如北地之平雙陸。番禺人多為之，南番亦能此。"

### 2.7 下赞双陆（广州系）
- 原文："下馬出局與羅嬴雙陸同。**凡遇雙采、雙幺、雙二、雙三之類，併移四馬**，如彩數。謂如擲雙三，則四馬皆進三路。又賞一擲。番禺人多為之。"（即 §1.3）

### 2.8 不打双陆（广州系）
- 原文："下馬出局如常法。**不用骰子，一人於暗處喝彩，皆以七為數**：或二五，或幺六，或四三。遇子不打，故謂之不打雙陸。番禺人能之。"
- 核心：无骰子、喊彩（2-5/1-6/4-3 拼 7）、**不打马**。

### 2.9 佛双陆（广州少儿戏）
- 原文："廣中兒輩為之。**各用十二馬**，更不布局，遇彩旋下。每一路置二馬，六路置馬十二。止在一門、二門、三門、四門（/匱屋/六頭屋），不過外六門，與敵馬相望，不復可打。或擲幺五，則就一五路下馬。如二四路各有雙馬，又擲二四則不下馬，得他彩方進。十二馬入局足，卻擲彩拈出。"
- 关键：**12 马**、不预布局、以二马成对（门前门/门屋），"不復可打"（防守型）。
- **引擎**：变体配置（`佛双陆` — 马数 12、不布局）。

### 2.10 三堆双陆（广州系）
- 原文："用二骰子，置馬為三處，如北地之三梁雙陸。進馬出局如常法。番禺人能之。"

### 2.11 四架八双陆（南番）
- 原文："盡用二骰子進馬出局，如羅嬴雙陸，惟馬子排置小。局終，**三馬作一屋，成五屋者，贏兩局**。"
- 关键：以"屋"计分，成五屋赢两局。

### 2.12 南皮双陆（南番）
- 原文："南皮、占城能之。布局與四架八雙陸同，進馬出局如常法。骰子以木或角為之而長，**無幺六**。"
- 关键：骰子无 1、6（只有 2–5？）——即"无公六"骰。

### 2.13 大食双陆（三骰）
- 原文："以毯為局，織成青地白路。**用三骰子，馬分為七**……十五馬至外六門未散，贏一雙采，賞一擲……馬先出贏小，敵馬未出，已馬出，贏大（棋之等局也）。"
- 关键：**三骰、马分七、双采赏一掷**。

### 2.14 日本双陆
- 原文："白木為盤，關可尺許，長尺有五，厚三寸，刻其中為路，置二骰子竹筒中撼而擲諸盤上，視其采以行馬。馬以青白二色琉璃為之，如中國棋子狀。**馬亢歸一處者為勝**。倭人甚好之，兩人對局自朝至暮不已，傍觀者亦移日不去。"
- 关键：**先到（归）一处者胜**（内盘/门内为胜，非拈出），与 CCTV 所引《双陆锦囊钞》一致。

## 3. 南北局例（卷五，v0.3 补全术语）

> 原文见 OCR（p431–p433）。要点：

- **北式**：以後一梁為"胲/孩"，前一梁為"門"，門最緊。
  - 兩馬至胲 → **把核**；拆一馬 → **拆核**。
  - 兩馬至門 → **把門**；拆一馬 → **拆門**。
  - 後六梁 → **宫马**；歸梁 → **入宫**（狄仁傑"雙陸不勝，宮中無子也"即指此）。
  - 兩馬相比為梁一道，**不得過六馬**。
  - 十五馬過門欲出；五、六路上馬多 → **頭重**（五、六大采不常有），宜自頭梁移下，則頭輕易出。
- **南式（番禺）**：
  - 從頭出 → **開腳**；兩子相比 → **做屋**，亦曰**一門屋**。
  - 一路曰一門、二路曰二門、三路曰三門、四路曰四門、五路曰匱屋、六路曰**六頭屋**；總謂之**内**。
  - 六門後六路曰**外六門**，後第一路亦曰六頭子。
  - 已出復入 → **落子**；二子相比 → **縛**（如四路上有馬，再有馬來即曰縛四）。
  - 進一步曰**上**，自出曰**喫子**；十子作一處亦可。
  - 南人對局已見敗證，則"頻打不許成屋"，謂之**合碎**（猶言翻局）；三佛齊、閣婆、占城曰**質犁**，真臘曰**莎則四**。

> 引擎影响：术语主要用于 UI 文案与教程；核心机制（把门/把核 = 成梁卡位；不得过六马 = 上限6；宫马/内 = 己方内盘）与现引擎一致，无需改动逻辑，仅需在 UI/文案层加入术语。

## 4. 卷五其他篇（盘马/骰子/赌赛/名称/杂记）要点

- **盘马**："北雙陸盤如棊盤之半而長，兩門二十四路皆刻出……馬底圓平而殺其上，長三寸二分，上徑四分，下徑寸一分，大抵如今人家所用搗衣椎（状）。" → 棋盘 24 路实证；马形如捣衣椎。
- **骰子**：各地骰子形制不同——三佛齊/閣婆/大食以木為骰六面；南皮/占城以烏木或角為之，長二寸許，**無幺六**；骰名各地异称（胡纏幺/薩/塗打/帝伽/暗/班浮/喃真等）。
- **赌赛**："北人以金銀、奴婢、羊馬為博……勝一局雙陸至多得二籌……先滿五籌為率……高者饒一籌……"
- **名稱**：北人打雙陸曰"打雙盤"“雙盤馬”“雙馬”；番禺曰"打雙陸"“雙陸板”“雙陸子”……
- **雜記**：北雙有五（平雙陸、三梁、七梁、打間、回回）；燕之茶肆多置局；番禺雙名有五（下讚、三堆、羅嬴、不打、佛雙陸）等。

## 5. 引擎配置扩展（v0.3 修订）

```ts
interface GameOptions {
  maxStack?: number            // 单梁上限，默认 6（"一道不得过六马"）
  doublesFourMoves?: boolean   // 双采走 4 步，默认 true（下赞/大食译"併移四馬"）
  doublesBonusRoll?: boolean   // 双采赏一掷（下赞/大食系），默认 false
  entryCanHit?: boolean        // 入局可打单立敌马，默认 true
  bearOffTolerance?: 'standard'|'arbitraryTwo'  // 拈出：标准按采数；回回双陆任意出两马
  diceCount?: 2 | 3            // 骰子数：2（常局/平/罗嬴…）；3（三梁/大食）
  pieceCount?: 12 | 15         // 马数：15（常局）；12（佛双陆）
  variant?: 'ping'|'da-jian'|'huihui'|'qiliang'|'sanliang'|'luoying'|'xia-zan'|'bu-da'|'fo'|'san-dui'|'si-jia-ba'|'nan-pi'|'da-shi'|'japan'
}
```

引擎 `rollDice` 支持 `diceCount`；`bearingMoves` 支持 `arbitraryTwo`；其它变体差异集中在**初始摆位（布局）**与**计分方式**，作为 `variant` 分支或后续扩展。
