## 2. 棋具与形制（《谱双·盘马》）

1. **棋盘**：长方形，「兩門二十四路」——两长边各刻 12 路，全盘 **24 梁**，中线两处**门**标分隔。以「六为限」（左右各十二路，分四区、每区六梁，符合"双六"之数）。
   - 实物参照：辽叶茂台 7 号墓漆木盘（52.8×25.4cm），每长边 12 骨片圆坑 + 新月门标，与《事林广记》"打双陆图"一致。
2. **马**：白黑**各 15 枚**，共 30。「白黑相偶」——双方在马数、走法上完全对偶。
3. **骰子**：**两枚**六面骰。《谱双·骰子》载各地骰子形制（木/乌木/角制等），中国主流两枚。※ 日本及西域有"无公六"等变体，不作默认。
4. **行马方向**：「白馬自右歸左，黑馬自左歸右」——双方相向而行，各行半周，自对侧成"叠梁/头梁"后拈出。

## 3. 核心规则（依《谱双·常局格制》）

### 3.1 开局摆位（T3 落定）
「右前六梁、左後一梁，各布五馬；右後六梁，二馬；左前二梁，三馬。白黑相偶。」

- 每方 15 马按 **5 / 5 / 2 / 3** 四组分布（双方中心对称）。
- 具体到梁的坐标见 §4 建模；因原文用方位词（右前/左后/右后/左前）而非统一编号，本稿在引擎层用 `INITIAL_POSITION` 常量给出确定坐标，并保证"白黑相偶"（镜像）。【评审确认坐标映射即可，无需改规则】
- 补充：一说与现代西洋双陆常用开局 {2,3,5,5} 同源（多集相同），可佐证此摆位。

### 3.2 行棋（走马）
「用骰子二，各以其采行。白馬自右歸左，黑馬自左歸右。或以二骰之數，共行一馬；或行二馬；或移或疊。」

1. 每回合掷**两枚**骰，得两个采数。
2. 可行方式（任选其一）：
   - **分走**：两骰采数分别用于**两枚马**各走一步；
   - **合走一马**：两骰采数相继用于**同一匹马**（先小后大或先大后小均可），但不可一步走两采之和；
   - 「或移或疊」指按步前进或叠放（同梁累积），即正常落子。
3. **双采（双骰同点）**：《谱双·常局格制》未明载；□ v0.2 采用**与西洋双陆通行的"该点走四步"**，但**这是资料缺省假设**。 【待定：D1 —— 是否采用双采走四步，若无据可改为"双采按两步处理"】
   - （对照：《谱双·第三卷"下讚/不打"等南式条》有"凡遇雙采……併移四馬"的记载，佐证双采走多步在南式存在，但**北双陆/常局格的常局**未明说。）

### 3.3 落点合法性与打马/卡位（T6 · 一手原文落定）
「凡馬單立，則敵馬可擊。兩馬相比為一梁，它馬既不得打，而不得同途。」

- **单立可击**：某梁**仅一枚敌马**（单立），己方马落到该梁，将该敌马**打下盘**；己方马占据该梁。
- **成一梁即安**：某梁**两枚及以上己方马**（两马相比为一梁），敌马**既不能打、也不能落地**（不得同途 = 不得落于其上），但可**从上方越过**。
- **上限**：「兩馬相比為一道，不得過六馬」——**单梁最多 6 马**（含防守成梁的堆叠上限）。

### 3.4 入局（下马）（T6 · 一手原文落定）
「凡遭打，必候元入局處空位，與采相當，始得下。謂如第二梁空，今摸得二采，則下。所打者未下，則它馬不得行。」

1. 被击下的马离开棋盘，进入"界外"等待。
2. **入局条件**：轮到该方，掷出采数 N 时，该马按点数自**入局处（起点侧）**进场；落点必须与采数相当（如"第二梁空，摸得二采则下"），且该梁**无两枚以上敌马**（空位/可落）。
3. **入局优先**：**在被击马全部入局之前，该方盘上其余马一律不得移动**。
4. 若采数对应的入局点被敌卡位挡住（不能落、不能打），则该步无法走（跳至另一采或轮回对方）。

> 说明：此即 v0.1 的"解释 A"，现在由原文直接坐实。入局点=界外按采数进场（约等于从起点区外沿进入）。

### 3.5 过门（叠梁区）与拈出（T7 · 一手原文落定）
「凡開後一梁為敵人地，若不獲他馬，即盡移歸頭梁之内。每擲視其采拈出二馬，數，有餘則取，不足則否。彩小不取，則併移歸下梁。常須固兩馬，不可移動，動則頭破。後六梁謂之末梁，馬先出，盡為勝。」

1. **过门**：己方全部马进入**叠梁（己方后六梁/末梁区域）**后，才可拈出。
2. **拈出**：每回合掷采，按采数拈出**内区马**：
   - 「有餘則取，不足則否」——采数足够时有马则取出；采数不足则否（即**不能比采数更短地取出**，只能取出位于该采数或更靠近门一侧的马——通常为"高位无子则低位可离"的宽容处理）。【D2：离盘用点的精确宽容规则，默认取"恰在采数位可取，若更高位无子则允许用采数移低位"】
   - 「彩小不取，則併移歸下梁」——若采数小且不想/不能取，可改用该采数在内区继续前行（归下梁）。
   - 「常須固兩馬，不可移動，動則頭破」——**叠梁/头梁位置需保持至少两马镇守**；若强行移动（如为了拈出一枚而破坏两枚镇守），则"头破"，风险敞口（这是战术惩罚，实现时作为可选的警告/限制）。【D3：是否将"头破"做成硬性限制，建议做成策略提示而非强制】
3. **拈出期间被打**：若有马被击下，须先全部入局并重新**过门**，方可继续拈出。

### 3.6 胜负与计筹（T10 · 一手原文落定）
「馬先出盡為勝，而他馬未歸梁，或歸梁而無一馬出局，則勝雙籌。」

- **胜**：先拈尽（全部 15 马出局）者胜。
- **计筹**（《谱双·常局格制》与《南北局例》一致）：
  - 胜方拈尽，若**对方尚未归梁**（未全部进己方内区），或**对方已归梁而未拈出任何马** → 胜**双筹**；
  - 否则胜**一**筹。
  - 「凡赏罚之筹，唯所约，无有定数」——**局外约定，不计入引擎强逻辑**；引擎只需产出一览（赢家 + 是否双筹）。【D4：比赛先到几筹由配置，默认"单局制"+可配置连战】
- **无 3 筹**、无"倍数方块"（倍数方块属西洋近代规则，不进入中式建模）。

## 4. 棋盘建模（引擎 + UI）

### 4.1 几何模型
- 24 梁编号 1–24，环形；划分为四区（每区 6 梁）——两门将盘分为前后两半。
- 白黑各有一条**自身行马方向的编号**（自右归左 / 自左归右），双方镜像相偶。
- 引擎采用单一坐标 `point: 1..24`，另存每方"前进方向 / 己方内区（叠梁）集合 / 起点（入局处）"三组索引；一切落点判定在统一坐标上换算。

```
俯视示意（两门在左右中线）：
   黑方内区(叠梁)  ←— 黑马行进 …
   ┌────────────────────────────────────────┐
   │ 19 20 21 22 23 24 │ 门 │ 13 14 15 16 17 18│
   │ 18 17 16 15 14 13 │ 门 │ 24 23 22 21 20 19│
   └────────────────────────────────────────┘
        … 白马行进 → 白方内区(叠梁)
（编号与朝向以最终 UI 稿为准；引擎以 1..24 环形编号为准。）
```

### 4.2 状态模型（引擎层，纯逻辑、可序列化）
```
梁: { white: int, black: int }[24]      // 各梁白/黑马数，成梁+上限6
界外: { white: int, black: int }        // 被打下待入局
出局: { white: int, black: int }        // 已拈出计数
turn: 'white' | 'black'
dice: [n1, n2] | null                   // 本回合采数
phase: 'roll' | 'move' | 'entry' | 'bearing' | 'ended'
record: Move[]                          // 走子记录（复盘/重放）
```
所有走法经 `legalMoves(state, dice) -> Move[]` 校验；对局 ID / 存档 / 联机重放共用此状态。

### 4.3 `INITIAL_POSITION`（开局摆位常量）
按《谱双》"5/5/2/3 白黑相偶"。形如：
```
白方：{ p5:5, p5b:5, p2:2, p3:3 }   // 映射到具体梁，见代码常量
黑方：白方镜像（中心对称）
```
摆位坐标为一手原文方位词（右前/右后/左前/左后）→ 统一编号的合理映射，随 `INITIAL_POSITION` 给注释说明。【评审确认映射即可，不改规则】

## 7. AI 与对局形态（PVE）

- PVE = 玩家 vs 简单 AI。AI 仅作用于**走子选择**；骰子由游戏内公平随机统一掷出，AI 不舞弊。
- 首版两档：
  1. **随机合法走**——验证引擎；
  2. **启发式贪心**——静态价值排序：优先能打马且安全 > 避免单立被击 > 落后/过门时优先前进与拈出 > 保持"固两马"防守。
- 后期：期望总点数差 / 浅层搜索，与 PVP 共享同一 `GameCore`。
